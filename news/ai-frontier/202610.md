【核心突破与模型发布】

1. Elorian｜Glimpse：把“反复看”纳入视觉推理过程｜2026-10-16
摘要：Elorian 发布视觉推理模型 Glimpse，支持在推理中重新查看视频片段、放大图像并调用多模态工具与子 Agent。官方报告其在部分计数、科学图表和机器人事件理解基准上达到或超过前沿模型，但仍需独立复测，不能据此认定整体领先。

2. NVIDIA｜Nemotron 3.5 Super VL：120B MoE 开放多模态 Agent 模型｜2026-10-15
摘要：新模型总参数120B、每Token激活12B，统一处理文本、图像、文档、视频与工具调用，并提供可定制权重、训练数据及后训练配方。NVIDIA 报告在其比较条件下单GPU Agent 吞吐可达同级开放模型的5倍，尚需结合真实工作负载验证。
推荐理由：多模态推理与工具执行正在汇入同一模型，开放权重和后训练工具使企业专用 Agent 的成本与部署路径更值得重新评估。
原文：https://developer.nvidia.com/blog/nvidia-nemotron-3-5-super-vl-powers-specialized-agents-with-multimodal-reasoning/

【前沿论文与技术路线】

推荐理由：Agent 从操作软件走向操作物理世界，关键不只是推理能力，而是可校验的状态、动作边界、回放证据与失败恢复。

推荐理由：长文档 Agent 的新重点是证据核验和跨章节一致性；可直接借鉴到技术方案、招标评分表和合同审查。

5. NVIDIA / Siemens EDA｜NeMo Gym：用最终交付物验证推动 Agent 可靠性提升｜2026-10-14｜微观信号
摘要：Siemens 在标准单元特征化任务中使用领域校验器评估最终 Liberty 文件，并据失败轨迹修改 Skill 与 MCP 工具描述；代表性基准的综合得分由约55%升至95%，Agent 轮次由155降至53。数据来自合作方实验，不宜直接外推至所有 Agent。
推荐理由：比起更换大模型，围绕最终结果设计校验器、追踪失败并修正工具接口，可能更快提升生产任务的质量与成本效率。
原文：https://developer.nvidia.com/blog/optimizing-agent-reliability-and-tool-calling-efficiency-for-chip-design-using-nvidia-nemo-gym/
