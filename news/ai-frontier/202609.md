2. Anthropic｜Sandbox Runtime denyUnlink：写权限不再自动等于删除/重命名权限｜2026-09-19｜微观信号（PR，尚未发布）
摘要：Anthropic 的 PR #572 指出一个很典型的沙箱权限缺口：`.git` 必须保持可写才能正常工作，但“可写”不应自动意味着允许 `rm` / rename；新方案为 macOS 增加 `filesystem.denyUnlink`，并在 Linux / Windows 无法可靠实现时直接拒绝该配置，而不是静默降级。
推荐理由：Agent 沙箱的权限模型需要从粗粒度 read / write 继续拆到 delete / rename 等不可逆动作；尤其应采用 fail-closed 语义，避免平台能力差异悄悄扩大 Agent 权限。
原文：https://github.com/anthropics/sandbox-runtime/pull/572

推荐理由：Agent 的模型路由不应按“总参数越大越好”设计，而应同时看 active parameters、显存、并发、任务难度与微调方式；高频明确步骤和少量高难推理可以采用不同模型层。
